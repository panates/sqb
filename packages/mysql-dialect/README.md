## About SQB

SQB is an extensible, multi-dialect SQL query builder and Database connection wrapper for NodeJS.

## About @sqb/mysql-dialect

This package registers the `mysql` SQL serialization dialect used by [`@sqb/mysql`](../mysql).
It is loaded automatically when `@sqb/mysql` is imported; you normally don't need to depend
on it directly.

## Installation

```bash
$ npm install @sqb/mysql-dialect --save
```

## Node Compatibility

- node >= 20.x
